§1 Countably topoi

Goal — 定理 A

A∈Gest⁡A\in\operatorname{Gest} に対し

Gest⁡/An-eˊtale は countably topos\operatorname{Gest}_{/A}^{n\text{-étale}}\text{ は countably topos}
注意

nn-étale への制限は現実的には十分.
例えば algebraic stack は 1-étale

notation：全ては (∞,1)(\infty,1) であり,いちいちことわらない.

Countably topostopos 界隈では通常 ℵ1\aleph_1-ary pretopos というとは Giraud の公理のうち可算性＝ℵ1\aleph_1-small な部分だけを取り出したもの.

Giraud の公理

presentable category CC に対して以下は同値

(i) ある小圏 SS と,左完全な到達可能局所化

PShv⁡(S)⟶C\operatorname{PShv}(S)\longrightarrow C

が存在.

(ii) CC：κ\kappa-presentable,CκC^\kappa：有限極限で閉として,Cκ→CC^\kappa\to C の Kan 拡張

PShv⁡(Cκ)⟶C\operatorname{PShv}(C^\kappa)\longrightarrow C

が有限極限を保つ

(iii) Giraud の公理が成立：

(a) 余極限 は universal

任意の射 f:Y→Xf:Y\to X に対し引き戻し C/X→C/YC_{/X}\to C_{/Y} が余極限を保つ

(b) 余積 は disjoint

任意の X,Y∈CX,Y\in C に対し

∅⟶Y↓↓X⟶X⊔Y\begin{matrix}\varnothing&\longrightarrow&Y\\\downarrow&&\downarrow\\X&\longrightarrow&X\sqcup Y\end{matrix}
(c) 亜群対象 は effective

X∙X_\bullet：単体的対象が亜群対象とは

∀nXn⟶X1×X0X1×X0⋯×X0X1⏟n 個\forall n\quad X_n\longrightarrow\underbrace{X_1\times_{X_0}X_1\times_{X_0}\cdots\times_{X_0}X_1}_{n\text{ 個}}

が同値であること,かつすべての射が可逆であること.

亜群対象 X∙X_\bullet が effective とは

∀nXn⟶X0×∣X∙∣X0×∣X∙∣⋯×∣X∙∣X0⏟n+1 個\forall n\quad X_n\longrightarrow\underbrace{X_0\times_{|X_\bullet|}X_0\times_{|X_\bullet|}\cdots\times_{|X_\bullet|}X_0}_{n+1\text{ 個}}

が同値であること.

任意の亜群対象が effective であることを要求する.

Giraud の公理において,(implicit に登場する) Grothendieck universe UU を regular cardinal ℵ1\aleph_1 に置きかえたのが countably topos である.

命題

CC：可算余極限と有限極限をもつ小圏とする.以下の条件は同値である：

(i) 有限極限を備えた小圏 SS と左完全局所化

PShv⁡(S)ℵ1⟶C\operatorname{PShv}(S)^{\aleph_1}\longrightarrow C

(ii)

PShv⁡(C)ℵ1⟶C\operatorname{PShv}(C)^{\aleph_1}\longrightarrow C

が有限極限を保つ.

(iii) Giraud の公理が成り立つ.

(a) 可算余極限 は universal
(b) 余積 は disjoint
(c) 亜群対象 は effective.

(iv) Ind⁡ℵ1(C)\operatorname{Ind}_{\aleph_1}(C) は topos

補題

SS を小圏とする.κ\kappa を regular cardinal とする.このとき X∈PShv⁡(S)κX\in\operatorname{PShv}(S)^\kappa は representable の κ\kappa-small 余積の幾何学的実現として書ける.

証明

ある κ\kappa-small 圏 II と関手 I→FSI\xrightarrow{F}S により

X=colim⁡i∈IFiX=\operatorname*{colim}_{i\in I}F_i

とかける.

(Δ↓I)(\Delta\downarrow I) を simplicial replacement とする.これは Cat⁡\operatorname{Cat} における slice 圏であり,対象を n∈ℕn\in\mathbb N と Δn→I\Delta^n\to I のペア,射を

Δn⟶I↓↗Δm\begin{matrix}\Delta^n&\longrightarrow&I\\\downarrow&\nearrow&\\\Delta^m&&\end{matrix}

という可換図式となるような 1-圏である.

関手 (Δ↓I)→LI, (Δn→αI)↦αn(\Delta\downarrow I)\xrightarrow{L}I,\ (\Delta^n\xrightarrow{\alpha}I)\mapsto\alpha_n は cofinal.

よって X=colim⁡x∈(Δ↓I)LUxX=\operatorname*{colim}_{x\in(\Delta\downarrow I)}LU_x.

さらに忘却関手 (Δ↓I)→Δ(\Delta\downarrow I)\to\Delta の各 nn の fiber (Δ↓I)n(\Delta\downarrow I)_n は discrete なので,

X=colim⁡n∈Δcolim⁡x∈(Δ↓I)nLUxX=\operatorname*{colim}_{n\in\Delta}\operatorname*{colim}_{x\in(\Delta\downarrow I)_n}LU_x

が欲しい表示を与える.

補題

SS を有限極限をもつ小圏,κ≥ℵ1\kappa\geq\aleph_1 を regular cardinal とする.PShv⁡(S)κ\operatorname{PShv}(S)^\kappa は有限極限で閉

証明

1∈S⊆PShv⁡(S)κ1\in S\subseteq\operatorname{PShv}(S)^\kappa.

ファイバー積についてしらべる.

Z↓X⟶Y∈PShv⁡(S)κ\begin{matrix}&&Z\\&&\downarrow\\X&\longrightarrow&Y\end{matrix}\quad\in\operatorname{PShv}(S)^\kappa

とする.

X,ZX,Z を SS の元の κ\kappa-small 余極限として X,Z∈SX,Z\in S に帰着してよい.

Y=colim⁡Y∙Y=\operatorname{colim}Y_\bullet,Y∙Y_\bullet は SS の元の κ\kappa-small 余積とする.

X,Z∈SX,Z\in S より射が X→Y0, Z→Y0X\to Y_0,\ Z\to Y_0 を通じて分解し,

X×YZ=X×Y0(Y0×YY0)×Y0ZX\times_Y Z=X\times_{Y_0}(Y_0\times_Y Y_0)\times_{Y_0}Z

• Y0×YY0∈PShv⁡(S)κY_0\times_Y Y_0\in\operatorname{PShv}(S)^\kappa

Y∙Y_\bullet に Kan の simplicial subdivision Ex⁡∞\operatorname{Ex}_\infty を施して Kan 複体 K∙K_\bullet にする.このとき κ\kappa-smallness は保たれる.

さらに

Y0×YY0=colimn(K∙Δn×Δ1×K∙Δn×∂Δ1(Y0×Y0))Y_0\times_Y Y_0=\operatorname*{colim}_n\left(K_\bullet^{\Delta^n\times\Delta^1}\times_{K_\bullet^{\Delta^n\times\partial\Delta^1}}(Y_0\times Y_0)\right)

よりこれは κ-presented.

• X,Z∈SX,Z\in S,YY：κ\kappa-small 余積 of representable のとき X×YZ∈PShv⁡(S)κX\times_Y Z\in\operatorname{PShv}(S)^\kappa

X,Z∈SX,Z\in S よりある成分 Yi,YjY_i,Y_j を通じて X→Yi↪Y, Z→Yj↪YX\to Y_i\hookrightarrow Y,\ Z\to Y_j\hookrightarrow Y と分解.

X×YZ=X×Yi(Yi×YYj)×YjZX\times_Y Z=X\times_{Y_i}(Y_i\times_Y Y_j)\times_{Y_j}Z

であり

Yi×YYj={Yii=j∅i≠j∈PShv⁡(S)κY_i\times_Y Y_j=\begin{cases}Y_i&i=j\\\varnothing&i\ne j\end{cases}\in\operatorname{PShv}(S)^\kappa

よって X×YZ∈PShv⁡(S)κX\times_Y Z\in\operatorname{PShv}(S)^\kappa

命題の証明

(ii) ⇒ (i) は自明.

(i) ⇒ (iv)

PShv⁡(S)=Ind⁡ℵ1(PShv⁡(S)ℵ1)⟶Ind⁡ℵ1(C)\operatorname{PShv}(S)=\operatorname{Ind}_{\aleph_1}(\operatorname{PShv}(S)^{\aleph_1})\longrightarrow\operatorname{Ind}_{\aleph_1}(C)

は左完全局所化.

(iv) のとき (ii)(iii) が明らかに成立.

(iii) ⇒ (ii) は一つ前の補題における有限極限の公式が保存されるから.

直観

Giraud の公理は内部型理論が上手くふるまうことを保障する.

topos型理論
有限極限1,Σ,=
κ-small 余極限κ-small 余積, quotient

であり,

topos型理論

ということに対応する.

ということである.

n=1234⋯∙∙∙∙⋯\begin{array}{ccccc}n=1&2&3&4&\cdots\\\bullet&\bullet&\bullet&\bullet&\cdots\end{array}

§2 nn-suave Stefanich ring の極限

以下の 2-圏 についての結果を用いる.

補題

C∈2Pr⁡\mathcal C\in2\operatorname{Pr} とする.II：可算圏,X:I→CX:I\to\mathcal C を diagram とする.

(i) Y∈C, Y→Flim⁡XiY\in\mathcal C,\ Y\xrightarrow{F}\lim X_i が,∀i∈I\forall i\in I に対し Fi:Y→XiF_i:Y\to X_i が左随伴をもつとする.

このとき FF は左随伴 FLF^L をもち,以下の形,

lim⁡IX⟶lim⁡IlaxX⟶lim⁡IlaxY≃Fun⁡(I,Y)→colim⁡Y.\lim_I X\longrightarrow\lim_I^{\mathrm{lax}}X\longrightarrow\lim_I^{\mathrm{lax}}Y\simeq\operatorname{Fun}(I,Y)\xrightarrow{\operatorname{colim}}Y.

従って FLF=colim⁡FiLFiF^LF=\operatorname{colim}F_i^LF_i

(ii) Y∈C, colim⁡Xi→FYY\in\mathcal C,\ \operatorname{colim}X_i\xrightarrow{F}Y が,∀i∈I\forall i\in I に対し Fi:Xi→YF_i:X_i\to Y が右随伴をもつとする.

このとき FF は右随伴 FRF^R をもち,以下の形,

Y⟶Fun⁡(I,colim⁡Xi)→colim⁡Icolim⁡Xi.Y\longrightarrow\operatorname{Fun}(I,\operatorname{colim}X_i)\xrightarrow{\operatorname{colim}_I}\operatorname{colim}X_i.

但し,一つ目の射は I×Y≃colim⁡IY→(FiR)colim⁡IXiI\times Y\simeq\operatorname{colim}_IY\xrightarrow{(F_i^R)}\operatorname{colim}_IX_i の curry 化.

従って FFR=colim⁡IFiFiRFF^R=\operatorname*{colim}_IF_iF_i^R.

命題

(i) StRing⁡A/n-suave\operatorname{StRing}_{A/}^{n\text{-suave}} は可算極限で閉.

さらに ∀m≥n\forall m\geq n に対し,

StRing⁡A/n-suave⟶Am+1op,B⟼(B/A)!\operatorname{StRing}_{A/}^{n\text{-suave}}\longrightarrow A_{m+1}^{\mathrm{op}},\quad B\longmapsto(B/A)^!

は可算極限を保つ.

(ii) ∀A→gC\forall A\xrightarrow{g}C に対し StRing⁡A/n-suave→StRing⁡C/n-suave\operatorname{StRing}_{A/}^{n\text{-suave}}\to\operatorname{StRing}_{C/}^{n\text{-suave}} は可算極限を保つ.

証明

II を可算圏,i↦B(i)i\mapsto B(i) を図式とする.

(i)

StRing⁡A/=lim⁡(CAlg⁡(A1)←CAlg⁡(A2)←⋯ )\operatorname{StRing}_{A/}=\lim(\operatorname{CAlg}(A_1)\leftarrow\operatorname{CAlg}(A_2)\leftarrow\cdots)

より各段階で極限を計算できる：

(lim⁡B(i))m=lim⁡(B(i)/A)m≕(B/A)m(\lim B(i))_m=\lim(B(i)/A)_m\mathrel{≕}(B/A)_m

m≥n+1m\geq n+1 のとき suave 性より 1→(B(i)/A)m1\to(B(i)/A)_m が左随伴をもつ.

従って補題より 1→(B/A)m1\to(B/A)_m ももち,各成分の余極限として書ける.

特に

(B/A)m−1!=colim⁡(B(i)/A)m−1!∈CoCAlg⁡(Am)(B/A)^!_{m-1}=\operatorname{colim}(B(i)/A)^!_{m-1}\in\operatorname{CoCAlg}(A_m)

さらに (B(i)/A)m!→1(B(i)/A)^!_m\to1 が右随伴をもつので,補題より (B/A)m!→1(B/A)^!_m\to1 ももつ.

(ii) A→BA\to B：nn-suave より

(B⊗AC)m≃(gm∗(B/A)m!)∨(B\otimes_A C)_m\simeq\bigl(g_m^*(B/A)^!_m\bigr)^\vee

である.

lim⁡(gm∗(B(i)/A)m!)∨≃(colim⁡gm∗(B(i)/A)m!)∨≃(gm∗(colim⁡(B(i)/A)m!))∨≃(gm∗(B/A)m!)∨.\begin{aligned}\lim\bigl(g_m^*(B(i)/A)^!_m\bigr)^\vee&\simeq\bigl(\operatorname{colim}\,g_m^*(B(i)/A)^!_m\bigr)^\vee\\&\simeq\bigl(g_m^*(\operatorname{colim}(B(i)/A)^!_m)\bigr)^\vee\\&\simeq\bigl(g_m^*(B/A)^!_m\bigr)^\vee.\end{aligned}

§3 proof

CC を subcanonical ℵ1\aleph_1-ary site とする：

(i) CC：有限極限を備えた small category.
(ii) 左完全局所化 PShv⁡(C)ℵ1→Shv⁡(C)ℵ1\operatorname{PShv}(C)^{\aleph_1}\to\operatorname{Shv}(C)^{\aleph_1} を備える
(iii) C↪Shv⁡(C)ℵ1C\hookrightarrow\operatorname{Shv}(C)^{\aleph_1}

O:Cop→StRing⁡A/n-eˊtale\mathcal O:C^{\mathrm{op}}\to\operatorname{StRing}_{A/}^{n\text{-étale}} は sheaf であり有限余極限を保つとする.

以下を示す.

定理 B

O:Shv⁡(C)ℵ1,op⟶StRing⁡A/\mathcal O:\operatorname{Shv}(C)^{\aleph_1,\mathrm{op}}\longrightarrow\operatorname{StRing}_{A/}

は StRing⁡A/n-eˊtale\operatorname{StRing}_{A/}^{n\text{-étale}} を通じて分解する.

定理 B ⇒ 定理 A

C=(StRing⁡A/n-eˊtale)opC=(\operatorname{StRing}_{A/}^{n\text{-étale}})^{\mathrm{op}} に trivial topology を備えたものとする.

A→BA\to B：nn-étale なので (B/A)m∈Am+1(B/A)_m\in A_{m+1} は dualizable なので ℵ1\aleph_1-コンパクト.

特に CC は small.

よって PShv⁡(StRing⁡A/n-eˊtale,op)ℵ1→StRing⁡A/n-eˊtale\operatorname{PShv}(\operatorname{StRing}_{A/}^{n\text{-étale},\mathrm{op}})^{\aleph_1}\to\operatorname{StRing}_{A/}^{n\text{-étale}} を得,有限極限を保つ.

系

• nn-étale AA-algebra は countable 余極限閉.
• さらにこの余極限は係数拡大と可換.

証明

まず ∀Y→fX\forall Y\xrightarrow{f}X に対し f∗:X→Yf^*:X\to Y が nn-suave であることを示す.

nn-suave は countable 極限で閉じているので X∈CX\in C のときでよい.

さらに ∀X′→X, X′∈C\forall X'\to X,\ X'\in C に対し

O(X′)⊗O(X)O(Y)≃O(X′×XY)\mathcal O(X')\otimes_{\mathcal O(X)}\mathcal O(Y)\simeq\mathcal O(X'\times_X Y)

よって X′↦(O(X′×XY)/O(X′))m!∈O(X′)m+1X'\mapsto(\mathcal O(X'\times_X Y)/\mathcal O(X'))^!_m\in\mathcal O(X')_{m+1} は引き戻しで保たれる.

降下により Bm!∈CoCAlg⁡(O(X)m+1)B_m^!\in\operatorname{CoCAlg}(\mathcal O(X)_{m+1}) を得,その representable X′→XX'\to X への引き戻しは (O(X′×XY)/O(X′))m!(\mathcal O(X'\times_X Y)/\mathcal O(X'))^!_m.

さらに同じく降下により Bm!→1B_m^!\to1 は右随伴 1→gm−1′Bm!1\xrightarrow{g'_{m-1}}B_m^! をもつ.

(Bm!)∨=Hom(Bm!,1)=limg:X′→Xgm*Hom((O(X′×XY)/O(X′))m!,1)=limg:X′→Xgm*(O(X′×XY)/O(X′))m=limg:X′→X(O(X′×XY)/O(X))m=(O(Y)/O(X))m

これにより gm−1′g'_{m-1} は 1→O(Y)/O(X)1\to\mathcal O(Y)/\mathcal O(X) の左随伴に移る.

さらにこの unit における値は

End(1)≃O(X)m1→Bm!→1↦unitにおける値∥1→O(Y)/O(X)→1

再び降下によりこれは Bm−1!B^!_{m-1} である.

以上により

• O(X)→O(Y)\mathcal O(X)\to\mathcal O(Y)：nn-suave
• O(X′)×O(X)O(Y)≃O(X′×XY)\mathcal O(X')\times_{\mathcal O(X)}\mathcal O(Y)\simeq\mathcal O(X'\times_X Y)

よって diagonal でくり返して,O(X)→O(Y)\mathcal O(X)\to\mathcal O(Y)：nn-étale
