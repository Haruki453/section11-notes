    §1 アフィン射

    1.1 S 上の前スキームと構造層上の代数

    原典番号内容
    1.1.1本文・構成: 構造射による構造層・加群層・代数層の順像の記法.
    1.1.2本文・構成: スキームの射と加群層の射から, 順像の代数層と加群層の射を得る反変関手.
    1.1.3本文・構成: スキームと加群層の組を, 代数層とその加群層の組に対応させる.

    1.2 前スキーム上のアフィン前スキーム

    原典番号内容
    1.2.1定義: 基底のアフィン開被覆の逆像がアフィンとなる相対アフィン前スキームの定義.
    1.2.2例: 閉部分スキームの構造射は相対アフィン.
    1.2.3注意: 相対アフィンなスキームがアフィンとは限らず, アフィンな始域の射も相対アフィンとは限らない.
    1.2.4命題: 相対アフィン前スキームの構造射は分離的.
    1.2.5命題: 相対アフィン性は基底の開集合への制限で保たれる.
    1.2.6命題: 相対アフィン射による準連接層の順像は準連接.
    1.2.7命題: 相対アフィンな終域への射は, 対応する代数層の準同型と一対一に対応する.
    1.2.8系: 相対アフィン前スキームの間の射が同型であることは, 対応する代数層の射が同型であることと同値.

    1.3 代数層に付随する相対アフィンスキーム

    原典番号内容
    1.3.1命題: 準連接代数層に付随する相対 Spec の存在と一意性.
    1.3.2系: 相対 Spec のアフィン開集合上の逆像は, 代数層の切断環の Spec.
    1.3.3例: 原点を二重化したアフィン平面への開はめ込みによる非アフィン射の例.
    1.3.4系: 基底がアフィンなら, 相対アフィン性とアフィン性は同値.
    1.3.5系: アフィン射上の前スキームが基底上でアフィンとなる条件.
    1.3.6本文・構成: 相対アフィン前スキーム上の相対アフィン前スキームと, 代数層上の代数層の対応.
    1.3.7系: 相対アフィン前スキームの有限型性は, 対応する代数層の有限型性と同値.
    1.3.8系: 相対アフィン前スキームの被約性は, 対応する代数層の被約性と同値.

    1.4 相対アフィンスキーム上の準連接層

    原典番号内容
    1.4.1命題: 相対アフィン前スキームと準連接層の組の射は, 代数層と加群層の組の射に対応する.
    1.4.2系: スキームと準連接層の組の同型を, 対応する代数層・加群層の同型で判定する.
    1.4.3命題: 準連接代数層とその準連接加群層から, 相対 Spec とその準連接層を一意に構成する.
    1.4.4系: 相対アフィン射の順像は準連接層上で完全で, 帰納極限・直和と可換.
    1.4.5系: 相対アフィン対応における加群層の有限型性の同値.
    1.4.6命題: 相対アフィン前スキームのファイバー積は, 代数層のテンソル積に対応する.
    1.4.7系: 外部テンソル積の順像と, 対応する加群層のテンソル積の同型.
    1.4.8本文・構成: 相対アフィン対応はテンソル積と可換. 有限表示の場合には Hom とも可換.
    1.4.9注意: 相対アフィン前スキームの有限直和は相対アフィン.
    1.4.10命題: 準連接イデアル層による閉部分スキームは, 商代数層の相対 Spec.
    1.4.11命題: 基底のイデアル層を相対 Spec に引き戻したイデアルと, 代数層で生成するイデアルの対応.

    1.5 基底の変更

    原典番号内容
    1.5.1命題: 相対アフィン性は基底変換で保たれる.
    1.5.2系: 相対アフィン射の準連接層の順像は基底変換と可換.
    1.5.3注意: アフィン性を外すと, 構造層の順像と基底変換は一般には可換でない.
    1.5.4系: 相対アフィン射の各ファイバーはアフィンスキーム.
    1.5.5系: アフィンな基底変換の後の構造代数層と加群層の記述.
    1.5.6本文・構成: 基底の射に沿った代数層の準同型から相対 Spec の射を構成する.

    1.6 アフィン射

    原典番号内容
    1.6.1本文・構成: アフィン射の定義.
    1.6.2命題: アフィン射は閉はめ込み・合成・基底変換・積で安定し, 分離的な後続射に対して相殺できる.
    1.6.3系: アフィンスキームからスキームへの射はアフィン.
    1.6.4命題: 局所ネーター基底上の有限型射のアフィン性は, 被約化で判定できる.

    1.7 加群層に付随するベクトル束

    原典番号内容
    1.7.1本文・構成: 対称代数の構成・普遍性と直和に対するテンソル積公式.
    1.7.2本文・構成: 対称代数の関手性と係数環の拡大との可換性.
    1.7.3本文・構成: 対称代数は局所化と可換.
    1.7.4本文・構成: 加群層の対称代数と, それが表す線形写像の関手.
    1.7.5本文・構成: 加群層の対称代数は環付き空間の射による逆像と可換.
    1.7.6命題: アフィンスキーム上の加群層の対称代数は, 対応する加群の対称代数に付随する層.
    1.7.7系: 準連接加群層の対称代数層は準連接. 有限型なら各対称冪も有限型.
    1.7.8定義: 加群層の対称代数の相対 Spec としてのベクトル束と, それが表す線形写像の関手.
    1.7.9本文・構成: ベクトル束の開集合上の切断は, 元の加群層から構造層への線形写像に対応する.
    1.7.10本文・構成: ベクトル束の体に値を持つ点は, 対応する係数拡大後の加群の双対ベクトルに対応する.
    1.7.11命題: ベクトル束の反変関手性・有限型性・直和と積の対応・基底変換・全射からの閉はめ込み.
    1.7.12本文・構成: 構造層に付随するベクトル束は相対アフィン直線. 自由加群層の場合の相対アフィン空間.
    1.7.13本文・構成: ベクトル束上の加法・零切断・スカラー倍による加群スキーム構造.
    1.7.14本文・構成: 加群スキームとしてのベクトル束から元の加群層を復元する.
    1.7.15命題: 準コンパクト性等の仮定の下で, 有限型アフィン射を有限型加群層のベクトル束に閉はめ込みする.

    §2 斉次スペクトル

    2.1.7系: ネーター次数付き環の Veronese 部分環はネーター.
    2.1.8本文・構成: 斉次素イデアルに属さない斉次元による乗法と, 素イデアルへの所属.
    2.1.9命題: 高次数成分のデータから斉次素イデアルを一意に復元する条件.
    2.1.10本文・構成: 正次数部分のイデアルと斉次素イデアルの定義.
    2.1.11本文・構成: 本質的整性の定義と, 次数零部分・正次数部分による整性の判定.

    2.2 次数付き環の分数環

    2.2.3本文・構成: 斉次局所化の間の標準準同型と次数零部分の間の写像.
    2.2.4補題: 積による次数零局所化は, 各因子による次数零局所化の像で生成される.
    2.2.5命題: 次数零局所化を Veronese 部分の商として記述する.
    2.2.6系: ネーター次数付き環の次数零局所化はネーター.
    2.2.7本文・構成: 斉次乗法集合による局所化・次数零部分と, 斉次素イデアルでの局所環.

    2.3 次数付き環の斉次素スペクトル

    原典番号内容
    2.3.1本文・構成: Proj を正次数イデアルを含まない斉次素イデアルの集合として定義する.
    2.3.2本文・構成: Proj の閉集合を定める集合と, 斉次イデアルによる記述.
    2.3.3本文・構成: Proj の位相と基本開集合の定義.
    2.3.4命題: 正次数の斉次元に対応する基本開集合は Proj の位相の基底.
    2.3.5本文・構成: Proj の基本開集合から次数零局所化の素スペクトルへの標準写像.
    2.3.6命題: Proj の基本開集合は次数零局所化の素スペクトルと同相.
    2.3.7系: 基本開集合が空であることは, 対応する斉次元の冪零性と同値.
    2.3.8系: 正次数部分集合が Proj 全体上で消える条件は, その元の冪零性.
    2.3.9系: 正次数イデアルの根基は, それを含む斉次素イデアルの共通部分.
    2.3.10本文・構成: Proj の部分集合上で消える正次数元のイデアル.
    2.3.11命題: イデアルの零点集合と根基, 部分集合の消滅イデアルと閉包の対応.
    2.3.12系: Proj の閉集合と正次数部分の根基斉次イデアルの反変な一対一対応.
    2.3.13系: 斉次イデアルの零点集合が空となる根基条件.
    2.3.14系: 基本開集合族が Proj を覆うことと, 対応する斉次元が正次数部分を根基で生成することの同値.
    2.3.15系: 基本開集合が基本開集合族の和に含まれる条件を, 生成イデアルへの冪の所属で表す.
    2.3.16系: Proj が空であることは正次数元がすべて冪零であることと同値.
    2.3.17系: Proj の既約閉集合は正次数部分の斉次素イデアルに対応する.

    2.4 Proj のスキーム構造

    原典番号内容

    2.5 次数付き加群に付随する層

    原典番号内容

    2.5.2命題: 各次数零局所化を貼り合わせる準連接層の存在と一意性.
    2.5.3定義: 次数付き加群に付随する Proj 上の層の定義.
    2.5.4命題: 次数付き加群から付随層への関手は完全で, 帰納極限・直和と可換.
    2.5.5命題: 付随層の茎は斉次素イデアルでの次数零局所化.
    2.5.6命題: 付随層の消滅と斉次元の冪による各元の消滅. 次数1生成の場合は必要十分.
    2.5.7命題: 斉次元に対応する基本開集合上で, その次数の倍数の捻りは自明.
    2.5.8系: 次数を固定した斉次元の基本開集合の和上では, 対応する捻り層は可逆.
    2.5.9系: 次数1で生成される場合, すべての整数次数の捻り層は可逆.
    2.5.10本文・構成: 構造層の捻りと加群層の捻りの定義.
    2.5.11本文・構成: 付随層のテンソル積からテンソル積加群の付随層への標準写像.
    2.5.12本文・構成: 次数付き Hom の付随層から層の Hom への標準写像.
    2.5.13命題: 次数1生成なら付随層はテンソル積と可換. 有限表示なら Hom とも可換.
    2.5.14系: 捻り層のテンソル積は次数の和の捻り層で, 負の次数は双対に対応する.
    2.5.15系: 加群の次数のずらしと付随層の捻りは一致する.
    2.5.16本文・構成: 次数零部分の置換と Veronese 部分への置換に対する捻り層の変化.
    2.5.17命題: 固定次数の斉次元の基本開集合の和上で, 正負の捻りの評価写像は同型.

    2.6 Proj 上の層に付随する次数付き加群

    原典番号内容
    2.6.1本文・構成: 捻り層の大域切断を集めた次数付き加群の定義.
    2.6.2本文・構成: 次数付き加群から付随層の捻り切断加群への標準写像.

    2.6.4本文・構成: 捻り切断加群の付随層から元の層への標準写像.

    2.7 有限性条件

    原典番号内容
    2.7.1命題: 次数付き環のネーター性・代数の有限型性から Proj の対応する有限性を得る.
    2.7.2本文・構成: 高次数部分の有限生成条件と高次数消滅条件, 高次数での単射・全射・同型の定義.
    2.7.3命題: 高次数部分が有限生成なら付随層は有限型. その消滅は高次数成分の消滅と同値.
    2.7.4系: 正次数イデアルが有限生成なら, Proj が空であることは高次数成分の消滅と同値.
    2.7.5定理: 有限個の次数1元で生成される場合, 準連接層をその捻り切断加群から復元できる.
    2.7.6注意: ネーター次数付き環では, 次数1生成から次数1有限生成が従う.
    2.7.7系: 同じ仮定の下で, すべての準連接層は次数付き加群の付随層となる.
    2.7.8系: 有限型準連接層は有限生成次数付き加群の付随層となる.
    2.7.9系: 有限型準連接層は十分大きく捻ると有限個の大域切断で生成される.
    2.7.9.1補題: 非負次数の捻り層は有限階数自由層の商となる.
    2.7.10系: 有限型準連接層は十分大きい負の捻り層の有限直和の商となる.
    2.7.11命題: 次数付き加群の復元写像と, 準連接部分層を次数付き部分加群で表す方法.

    2.8 関手的性質
